# 印尼查询缺少法规正文：修复记录

## 问题与根因

用户查询“印尼＋印尼国籍＋通用规则”后成功生成报告，但五项实质答案均为未知。原报告已定位官方 PP 35/2021、UU 6/2023 等法规介绍页，未取得条文正文。

原因是旧网页读取工具只支持 HTML/纯文本、响应上限为 2 MB；法规正文嵌入 iframe 中未被作为链接发现，找到的译文 PDF 又超过大小限制。官方站点大文件单连接下载较慢，加剧了读取失败。

## 修复

- 发现 iframe/embed/object 中的 PDF 链接，正确处理 URL 中空格和预览片段。
- 增加声明的 pypdf 依赖，支持至多 20 MB 的文本 PDF；扫描件没有可读文字时明确报错，不假称已完成 OCR。
- 默认读前 5 页，可按物理页码分段读取至多 12 页，或先关键词定位再读命中页。关键词片段只作为定位线索。
- 支持服务器的 HTTP Range 分段下载；校验总长度、片段位置、实际字节数、最终 URL 及版本标识，失败不返回部分文件。仅在本次研究进程缓存 PDF 字节。
- 保留原有公共 IP、重定向、大小和解析进程超时限制；本机调用共享 600 秒总预算，研究与必要的无工具恢复整理各最多 300 秒。
- 报告记录 PDF 实际读取页码、总页数和提取方式；来源标签改为“工具已读取内容”，避免将介绍页读取称为法规条文核验。

## 验证原则

单元测试使用可复现的 PDF 文本和分段响应。真实复测沿用用户原输入，必须检查答案是否由实际条文支撑，并保留修订、裁判或个案适用方面未解决的限制。不得通过删除“未知”字样或填入模型记忆制造成功结果。

## 已完成验证

207 项离线测试通过。实际条文读取和中断后恢复整理已验证，具体范围见 [验证记录](validation.md)；未声明所有现行法律与判例均已核验。
